# Finlog

Сайт на HTML, CSS и JavaScript и маленький сервер `server.js` для функций с нейросетью.

## Без нейросети
Откройте `index.html` в браузере. Всё работает, кроме блока «Календарь событий»
(он сообщит, что нейросеть недоступна).

## С нейросетью GigaChat
1. Зарегистрируйтесь на developers.sber.ru, создайте проект GigaChat API и получите Authorization Key.
2. Скопируйте `.env.example` в `.env` и вставьте ключ.
3. Сертификат: серверы Сбера используют корневой сертификат НУЦ Минцифры. Скачайте его (инструкция в документации
   Sber Developers) и запускайте так: `NODE_EXTRA_CA_CERTS=путь/к/сертификату.pem node server.js`.
   Для быстрого теста вместо этого можно поставить `GIGACHAT_INSECURE=1` в `.env`.
4. Нужен Node.js 18 или новее. Выполните `node server.js` и откройте http://127.0.0.1:3000

## Как работает календарь событий
Пользователь выбирает дату, сайт обращается к серверу (`/api/day`). Сервер ищет в интернете материалы об этом дне,
передаёт их в GigaChat и возвращает список главных событий. У самой нейросети встроенного поиска нет,
поэтому «свежесть» дают результаты поиска. Ответ по одной дате хранится 6 часов.

## Вопрос эксперту
Форма на странице «О нас» отправляет вопрос на `/api/ask`: сервер находит свежие материалы в интернете и просит GigaChat ответить на их основе. Ответ помечен как ИИ и не является инвестсоветом.

## Важно
- Ключ GigaChat нельзя класть в файлы страниц и публиковать. Он хранится только в `.env`.
- На GitHub Pages и других статических хостингах `server.js` не запускается, там блок покажет сообщение об ошибке.
- Нейросеть может ошибаться в датах, важные события стоит проверять в других источниках.
